# 武科大 Wiki 安卓客户端

安卓客户端使用首页、课表、校园和个人四个固定栏目。栏目与详情的具体对应关系见[参考 APK 拆包记录](./reference-layout.md)。教务登录和退出集中在个人栏目。首页的今日课程和周课表共用本机七天缓存。以北京时间确定当前日期，以 Wiki 已核实的学期起点换算周次。七列依次对应周一至周日。彩色卡片显示当周课程，灰色显示其他周的排课，同一时段另有其他周的不同课程时显示角标。点卡片可以查看该时段各门课的周次、节次、地点和教师。暂时无法解析的周次和节次在网格下方展示。

周课表按原助手的七列周视图布局：点标题可以查看各周的缩略排课，左右滑动换周。星期与日期留在顶部，两节课共用起止时间；同一时段的课程详情列出实际节次、上课周、教师与地点。选周条和箭头共用展开时钟，换周时课程列跟随手指平移，相邻周同步出现，松手后滑入并恢复到完全不透明。系统减少动态效果时直接呈现目标状态。课程颜色在整个学期内固定，缺少节次的记录单列。上课时间工具与课表共用校区，首页摘要按连续节次显示对应校区的起止时间。

## 0.6.15 页面间距与洗衣订单

保留周次滑选，恢复其他界面的原有间距。洗衣点和设备列表都可从「我的洗衣」打开订单，胖乖登录完成后自动返回订单列表。

## 0.6.14 周次选择与页面布局

新增上课时段默认按周重复。点选或滑过周次格可调整上课周。首页、常用页面和底栏采用更紧凑的间距。

## 0.6.13 自定义课程

在「个人 → 设置」开启「启动时打开课表」，下次启动 App 时直接进入周课表。关闭开关后，下次启动进入首页。

课表右上角「＋」可添加课程和多个上课时段。课程详情内可直接补一个时段，本机时段可单独编辑或删除。支持按日期加一次课和选择任意教学周。自定义课与教务课同时出现在周课表与今日课表，教务同步只更新学校安排。

## 0.6.12 设置、教务同步与学校通知

登录成功后自动同步一次课表与成绩。首页和周课表共用课表缓存，成绩查询与绩点计算共用本次登录取得的成绩。成绩查询右上角可手动刷新。

在「个人 → 设置」切换跟随系统、浅色或深色主题，也可开启低性能模式以简化转场与内容动效。加载提示延迟 0.5 秒。公共学校通知可直接阅读，需认证的通知通过「登录查看原文」在应用内打开校方页面。武科大导航沿用网页版的分组与 Lucide 图标。

## 0.6.10 生活工具

移除独立的床铺尺寸工具。

## 0.6.9 首页工具分类

首页和「更多工具」统一按学习、生活分组。固定的工具排在所属分组前面，取消固定后恢复原顺序。

## 0.6.8 首页与主修进度

首页按分组显示全部工具。固定项移到常用工具区最前面，取消固定后回到原分组。今日课程把上课状态和课程名称并列，近两周考试的日期和开考时间在倒计时下方右对齐。

主修进度先显示已修学分和完成概览，课程统计、毕业学分完成情况、通识选修类别和培养方案课程明细可分别打开。明细复用总览的教务查询结果。

## 0.6.7 首页固定工具

「更多工具」每行右侧的图钉可将工具固定到首页，已固定的工具再次点击即可取消。固定顺序保存在本机。

## 0.6.6 首页与常用地点

首页突出下节课开课时间和未来两周的考试倒计时，常用工具保留查成绩、算绩点、查宿舍和看洗衣机。其他功能在「更多工具」按用途分组。学籍信息在「个人」，原始课表导出在「课表设置」，个人培养方案在培养方案页。

洗衣机记住上次选择的地点和楼栋、楼层或机号筛选，再次进入时直接更新符合筛选的空闲设备。点「更换地点」选择其他洗衣点。学分进度和第二课堂优先展示已获、要求和剩余学分。

## 0.6.5 图书馆、洗衣机与课表

图书馆首屏展示当前借阅及应还日期，切换「即将到期」使用同批已取得的数据。账户概览、滞纳金、请求和书单收在右上角菜单。洗衣机首页直接展示附近洗衣点及空闲数，点整行看机号。「我的洗衣」承载登录和订单。设备页保留顶栏刷新，空闲数量和机号来自当次查询。

绩点默认使用已有教务成绩，底部提供「从零开始计算」。教学周入口合入课表，选周栏采用更窄的卡片和铺宽的缩略网格。首页今日课表按当日课程画时间轴，课程颜色和列表标记对应。

学校账号登录后同步默认考试安排，首页显示未来十四天的考试和考场。「考试倒计时」自动显示该批考试，时间未公布的考试也会列出。手动倒计时仍保存在本机。

## 0.6.4 首页与工具

首页保留今日课表，新增「完整课表」操作。常用入口独立摆放，其他工具归入学业、校内服务和校园生活。入口事件、贴纸和路由沿用现有组件。工具页根据任务显示紧凑表单、列表、详情或结果卡片。宿舍区域直接点选，上课时间按上午、下午和晚上分组，竞赛详情点开查看。

登录、课表同步、成绩和校内服务共用 `lib/school_operation_status.dart`。卡片跟随认证与查询阶段，显示已等待时间与实际尝试次数，响应系统减少动态效果。密码错误在输入框提示修改，现有认证层停止重试。[布局参考](./reference-layout.md)

## 0.6.3 考试倒计时与校内服务

首页的「考试倒计时」可以离线添加、编辑和删除科目，设置时间与考场备注。考试安排有记录时，可以带入科目、考场和已明确的开始时间，确认后保存到本机。倒计时按考试时间排序，到点后移入列表末尾。

图书馆、校车和第二课堂的官方页面可以在 App 内打开。原生查询由统一认证会话为各业务建立独立会话。 [统一认证与验证记录](./migration/unified-0.6.3.md)

## 0.6.3 工具二级页预览

从首页进入的成绩查询、学校通知和校车沿用原入口。成绩按学期分组，单门课程并列显示成绩、学分和绩点。通知以标题和发布日期为主，点整行打开正文。校车按行驶方向分组，发车时间置于每行左侧，右侧显示运行日期和线路。

布局参考武科大助手 APK 中的成绩、通知与校车资源。Wiki 使用原有 Flutter 主题、数据和路由实现，源码入口为 `lib/grade_results.dart`、`lib/foundation_service_page.dart`。组件与参考资源的对应关系见 [拆包记录](./reference-layout.md)。

0.6.2 在图书馆、校车和第二课堂缺少学校授权时提供官方网页入口。

## 数据与页面

### 0.6.3 本机教务与校园服务

业务统一为 Dart，保留现有四栏、文章阅读器与动效。Android 7+ 支持本机账号密码入口，Keystore 加密保存密码与会话；有效会话复用，过期使用已存密码，首次失败后最多重试四次，取消立即中断。学校网页和微信入口继续保留，并使用原 Wiki 后端。

教务、通知、图书馆、校车、第二课堂及洗衣机均由 Dart 实现。新增服务页使用 Flutter 表单、字段卡片与动作导航，提供 PDF 和系统文件导出，短信需要明确确认。图书馆／校车／第二课堂仍需 TGT；教务 CAS 登录不产生 TGT，缺少即提示，不伪造成功。

完整合同见 [接口总册](migration/api.md)、[教务接口](migration/academic-port.md)、[校园与洗衣接口](migration/campus-port.md)，当前实际验证及边界见 [集成记录](foundation-integration.md)。源码入口为 `lib/foundation/`、`lib/foundation_service_page.dart`；Android 系统适配在 `android/app/src/main/java/com/wustacm/wiki/`。Swift 原始快照仅保留为行为与许可来源，Flutter 构建不再需要 Swift 工具链。

校园概览复用 Wiki 首页的 14 个卡片入口，按校园、学习、生活和 Coder 分组。切换分类可查看该主题的其他文章，站点资料收在关于。课程安排、成绩、竞赛和地图卡片进入 App 内相应功能。

- `lib/academic.dart` 通过 `POST /api/academic` 建立学校统一认证会话。学校统一认证页在应用内打开，由原页面处理密码和验证码，也可用微信或另一台设备扫码。客户端轮询同一会话，课表和成绩共用登录状态。重新打开应用后，首次查询前核对已保存的会话。同步课表留在课表栏目，成绩查询留在学业服务。[教务会话协议](../docs/academic-query.md)
- `lib/week.dart` 绘制周视图。`lib/grade_selection.dart` 按编号归组重修记录，允许手选待计入的成绩。成绩只保存在当前查询页内存里。Android 升级时尝试从旧 WebView 的私有存储迁入有效课表缓存和教务登录态。
- `lib/native_pages.dart` 实现作息表、手工加权绩点、竞赛查询、培养方案索引、周边地图、导航和文章阅读。文章详情使用原生导航和随包 Vue 正文渲染器。Android WebView 从 APK 内的 wiki-reader.zip 读取文章、原站组件、JS、CSS 和路由数据。栏目、课程网格和工具仍由 Flutter 绘制。文章转场完成后创建正文视图。WebView 先布置正文动画首帧并确认已提交，Flutter 再撤掉占位并开始播放。远端图片独立加载。地图瓦片、网络图片、校方附件及站外链接需要网络。
- `lib/dorm.dart` 提供独立的宿舍页面。用户在 Flutter 中选择区域、输入寝室号并查看结果，人机验证由宿舍服务的官方页面在受限 Android WebView 内显示。需要用户本人完成验证码。
- 页面装配在 `lib/main.dart`，安卓平台功能在 `android/app/src/main/java/com/wustacm/wiki/`。配色沿用 Wiki 的 blue / zinc，深色背景、面板和边框与站点一致；小字使用更深的蓝，博客正文继续采用原组件的局部色值。应用跟随系统深浅色。布局参考用户提供的周课表截图与武科大助手。栏目切换直接复用 Wenku8_Flutter 的 archive_motion，页面进退适配其 Cupertino 转场，响应系统减少动态效果设置。[动效上游版本](https://github.com/mikufoxxx/Wenku8_Flutter/tree/f2272e8fa40ef005097c58e60b85a9197aa8b0aa)

原生工具页在 `lib/blog_surface.dart` 适配 blog-v3 的主题蓝、青色强调色和渐变卡片。切换校区、目录筛选和查询结果时复用 Wenku8 的 ArchiveReveal，入口的按压回弹参数来自上游 app_ui.dart 的 LiquidGlass。正文在 Nuxt 启动前同步 App 的深浅色偏好，沿用随包原版 CSS 和组件，首次可见后撤去加载层。

工具与成绩目录使用与卡片轮廓一致的点击反馈。校园分类保留固定标签宽度，成绩和培养方案的展开状态分别通过箭头与选中底色呈现。

阅读器为表格、Mermaid 和 FeedCard 提供触屏操作入口，复用原 Vue 组件的浮层。组件示例的代码、字体、公式和交互脚本随 APK 提供，站外视频和图片依赖源站。

深色课表使用 Catppuccin Mocha 的马卡龙色，与 Wiki 深色面板混合。课程名与教室分别居中，角标由卡片圆角直接裁剪。[配色来源](https://catppuccin.com/palette/#mocha)

底栏以 Wenku8 的弹簧参数跟手移动，切栏时隔离前一栏的焦点、触点和语义。通过工具或文章入口打开二级页时，入口图标过渡到页标题。课表详情使用共享弹层时序。加载占位保持不透明，直到 WebView 提交已准备的正文首帧。

一级栏目与课表弹层的标题共享转场时钟。二级标题从路由完成后开始横向揭示，文章正文随阅读进度按小节错峰入场，标题横向揭示，短段落和列表纵向展开，长内容与组件轻抬淡入。首页课程、校园工具、课表列、个人登录状态、宿舍表单和查询结果、成绩和各类目录均使用分组入场。Coder 文章和卡片也通过正文渲染器分组入场。入口图标直接复用 Wenku8 的纸面飞行，先揭起、沿弧线飞至目标，再斜向贴合。飞行全程保留入口贴图，贴合时换成标题图标，落点带轻微水纹。底栏选中使用一枚蓝色指示器跟手移动，首尾两侧在栏内保留弹簧越位再归中的动画。开启减少动态效果时直接显示。

## 构建

使用 Flutter 3.41.5、Android SDK 36、NDK 28.2.13676358 和 JDK 17。从源码构建时，先在仓库根目录安装锁定的网页依赖并生成 Android 资源。

```sh
pnpm install --frozen-lockfile
pnpm generate
node mobile/scripts/build-native-data.mjs
node mobile/scripts/build-tools.mjs
python mobile/scripts/build-reader.py
```

在 `mobile/` 执行：

```sh
flutter pub get
flutter test
flutter build apk --release
```

预览包使用调试签名，包名为 `com.wustacm.wiki`。新增 WUSTFoundation 模块采用 AGPL-3.0，组合移动端按 AGPL-3.0 分发；其他组件保留原有许可，上游文本及声明位于 `licenses/`。

## 安卓更新发布

「个人 → 检查更新」读取 `https://download.wust.club/wiki/latest.json`，根据设备架构和实际 APK 版本码选择下载包。

1. 在 Cloudflare R2 创建 `wust-wiki-downloads`，从桶的 **Settings → Custom Domains** 绑定 `download.wust.club`。在 `wust.club` 的 **Caching → Cache Rules** 对该域名的 `/wiki/latest.json` 设为绕过缓存。
2. 在 GitHub 仓库的 **Settings → Secrets and variables → Actions** 添加 `R2_ACCESS_KEY_ID`、`R2_SECRET_ACCESS_KEY`（仅该桶对象读写）和 `ANDROID_KEYSTORE_BASE64`、`ANDROID_STORE_PASSWORD`、`ANDROID_KEY_ALIAS`、`ANDROID_KEY_PASSWORD`。添加变量 `R2_ENDPOINT`，值使用该 R2 账户的 HTTPS S3 地址。
3. 更新 `pubspec.yaml` 中的版本和 `release-notes.txt`，推送与版本名一致的 `android-vX.Y.Z` 标签。流水线从签名成品读取版本码和校验值，用 App 同款 Dart 网络请求校验两个公开下载后发布清单。

发版前可在 **Actions → Android release → Run workflow** 手动验证构建和签名。更新源由正式版本标签触发发布。

从仓库根目录运行 `python mobile/scripts/publish-update.py verify --release <本地发布文件目录>` 可复核已发布的清单和两个 APK。这一步需要 PATH 中有 `dart`。

首个正式签名包由用户手动安装。旧调试签名包与正式包的覆盖安装取决于签名兼容性。后续正式发行沿用同一签名证书，每个架构的版本码递增。

0.6.3修复滑块轨迹、末点精度和实际计时；实测成功率、定位与滑动提交隔离证据见 [滑块回归记录](migration/slider-0.6.3.md)，不将模拟器结果当手机验收。

0.6.3 将统一认证 SSO 与各业务 Cookie 分开维护；明确密码错误立即停止并要求更新密码。登录、教务和校园服务共用实际过程状态，显示处理阶段、重试与等待时间。完整说明见 migration/unified-0.6.3.md 和 migration/api.md。
