## 关于“大类招生”

武科大部分专业在高考招生阶段并不直接按照单个专业招生，而是以“专业类”的形式录取，入学后再按照学校相应培养和分流方案进入具体专业。

2026 年涉及的主要大类包括：

| 招生大类             | 包含专业                                                     |
| -------------------- | ------------------------------------------------------------ |
| 材料类               | 材料成型及控制工程、无机非金属材料工程、金属材料工程、功能材料 |
| 自动化类（电子信息） | 电子信息工程、通信工程                                       |
| 法学类               | 法学、社会工作                                               |
| 管理科学与工程类     | 信息管理与信息系统、工程管理、物流管理                       |
| 工商管理类           | 会计学、工商管理                                             |
| 机械类               | 机械工程、机械电子工程、智能制造工程、测控技术与仪器、工业工程 |
| 计算机类             | 计算机科学与技术、软件工程、智能科学与技术                   |
| 自动化类             | 自动化、机器人工程                                           |
| 设计学类             | 视觉传达设计、产品设计、环境设计                             |
| 矿业类               | 智能采矿工程、采矿工程、矿物加工工程                         |
