# Coder 目录实现与验证

日期：2026-09-13。

来源：xupt-wiki/xupt-wiki，提交 `f1ba156d8f91374422921df51a9bc26703c298ab`。读取了上游 LabList、LabItem、BlogList、BlogCard、CoderGuild 实现及 labs/blog JSON；未把参考数据改名为 WUST 数据。

## 实现

- Markdown 中调用 `CoderDirectory`，包含 20 个实验室、35 个博客的参考快照。
- 实验室详情翻面、键盘操作、群号复制、官网/GitHub/培养计划跳转。
- 博客访问、GitHub、RSS 复制；实验室和博客均支持随机排序与 `?shuffle=false`。
- 频道折叠入口、访问链接和本地生成的二维码（内容为 `https://pd.qq.com/g/xiyoumanong`）。
- 头像仅在客户端加载，加载前和失败时使用文字占位；剪贴板失败显示可手动复制的值。
- 源站相对培养计划链接补全为源站 URL。在线信息表保留为外部链接，未实现自动拉取或在线编辑服务。

## 验证

- 内容链接检查：30 篇文档、15 个首页入口、43 个内部链接（含静态图片）。
- Nuxt 静态生成完成，103 条预渲染路由；类型检查退出 0。
- Edge 无头浏览器实测卡片数量、翻面/返回、键盘 Enter、群号/RSS 剪贴板内容、权限拒绝提示、随机排序保持成员集合、固定初始顺序、培养计划链接和博客链接。
- 390px 窄屏无横向溢出；检查浅色、深色截图；模拟头像网络失败。
- `/components` 实测链接卡片、提示框、折叠块和折叠内 Markdown，未发现页面运行异常。

环境仍有上游可选 vue-router 语言插件解析警告和构建依赖警告；网络不稳定时图标预取可能警告。未验证第三方博客的持续可用性、校园资料时效或线上部署。
